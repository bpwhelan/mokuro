# Claude Development Memory

## Version Management
- **ALWAYS** increment the version number when making changes to API server files
- Use semantic versioning: x.x.x format
- Increment the patch version (last number) for bug fixes and minor changes
- Example: 0.1.1 → 0.1.2 → 0.1.3

## Project Structure
- Docker configurations available for containerized deployment
- Server runs on port 7331 by default
