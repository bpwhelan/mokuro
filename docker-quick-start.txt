MOKURO SERVER DOCKER QUICK START
================================

1. BUILD THE IMAGE:
   ./build-docker.sh

   Or manually:
   docker build -f Dockerfile.server -t mokuro-server:latest .

2. RUN THE SERVER:
   # Basic:
   docker run -p 7331:7331 mokuro-server:latest

   # With persistent cache:
   docker run -p 7331:7331 -v mokuro-models:/root/.cache mokuro-server:latest

   # With docker-compose:
   docker-compose -f docker-compose.server.yml up

3. TEST THE API:
   # Health check:
   curl http://localhost:7331/health

   # Process image with manga-ocr:
   curl -X POST -F "image=@test.jpg" http://localhost:7331/api/ocr

   # Process image with Google Lens:
   curl -X POST -F "image=@test.jpg" -F "ocr_engine=lens" http://localhost:7331/api/ocr

4. VIEW LOGS:
   docker logs mokuro-server
   docker-compose -f docker-compose.server.yml logs -f

5. STOP THE SERVER:
   docker stop mokuro-server
   docker-compose -f docker-compose.server.yml down

For detailed documentation, see DOCKER_GUIDE.md
